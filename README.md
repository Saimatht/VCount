# VCount
VCount - Volleyball Counter (App)
Created an App for counting Volleyball games easily.
You can change max-points and point-difference in the settings, aswell as how many points you want to give a team, when you're playing with customized rules.
Save your games, import and export them in the settings and also choose your preferred design, giving you the best comfort when watching a volleyball game and counting.
